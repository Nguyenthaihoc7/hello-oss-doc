# \# Hello OSS

# 

# \## Giới thiệu

# 

# Hello OSS là một dự án phần mềm mã nguồn mở đơn giản được viết bằng ngôn ngữ C. Chương trình in ra màn hình dòng chữ "Hello OSS!".

# 

# \## Mục tiêu

# 

# \- Làm quen với việc xây dựng một dự án mã nguồn mở.

# \- Thực hành quản lý mã nguồn bằng Git và GitHub.

# \- Học cách viết tài liệu README, CONTRIBUTING và sử dụng giấy phép OSS.

# 

# \## Yêu cầu

# 

# \- Trình biên dịch C hỗ trợ GCC.

# \- Hệ điều hành Windows, Linux hoặc môi trường tương thích.

# 

# \## Build và chạy

# 

# Biên dịch chương trình:

# 

# ```bash

# gcc main.c -o hello

# ```

# 

# Chạy trên Windows:

# 

# ```bash

# hello.exe

# ```

# 

# Chạy trên Linux:

# 

# ```bash

# ./hello

# ```

# 

# \## Kết quả

# 

# ```text

# Hello OSS!

# ```

#

#
